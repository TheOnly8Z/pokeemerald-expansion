# Tianlan Crisis

Tianlan Crisis is a short (~2-3h playtime) romhack based on [pokeemerald-expansion 1.10.2](https://github.com/rh-hideout/pokeemerald-expansion/). Sent to an island experiencing abnormal weather, you are tasked with investigating and helping the people on the island before it is too late.

This romhack uses modern gen mechanics and features Pokémon from gens 1-3, and uses double battles exclusively.
There is some non-linear progression, and XP/money gain is dramatically increased. The difficulty is higher than base Emerald, but isn't intended to be brutal or kaizo-like.
That said, I may have balanced encounter difficulty poorly, so maybe don't blind Nuzlocke this. Also I preemptively apologize for the final battle. The voices in my head won.

The romhack is not fully finished. There is currently is no postgame content, not all base features from the game are present (such as daycare), and some areas may be rough and unfinished. I appreciate any feedback.
